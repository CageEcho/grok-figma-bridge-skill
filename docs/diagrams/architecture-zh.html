1 · Grok Bot

远程 HTTP MCP

使用远程 HTTP 连接器（transport: http）和 Bearer 请求头。本地命令连接器跑在 Bot 自己的电脑上，到不了你电脑里的 Figma。

2 · 你的电脑

Tailscale Serve

只走 tailnet 内的私有 HTTPS，反代到 127.0.0.1。不要打开 Funnel。占位主机名：YOUR_DEVICE.YOUR_TAILNET.ts.net。

回环
3 · 本包

新的 HTTP 网关

127.0.0.1 上的鉴权 Streamable HTTP MCP，只拉起一个常驻 stdio 子进程。这是基于公开 MCP SDK 的新助手，不是原来的私有脚本。

stdio
4 · Figma Desktop

插件面板

加固后的 figma-unified-mcp 把 WebSocket 18211 绑在 127.0.0.1。面板和文件保持打开，并显示绿色 Connected。

另一次历史验收，2026-11-25当时已有的 Grok Bot 设置完成了画布读取、临时矩形创建、读回和删除。106 个工具，没有 Figma REST token。那次设置不是这个新助手。
本包实际做过的检查用模拟 stdio 子进程测试了鉴权、initialize、tools/list、tools/call、单一后端和清理。没有在一台干净的同事电脑上做端到端测试。
面板保持打开。 在目标 Figma Desktop 文件里打开 figma-unified-mcp，确认绿色 Connected 后再操作画布。可以切换到其他应用。断开后先重连，再重试。
