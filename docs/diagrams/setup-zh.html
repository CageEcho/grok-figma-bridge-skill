在你自己的电脑上的最短安装

流程示意图 · 不是截图
1

固定版本并打补丁

fetch-upstream.mjs 检出指定提交，核对已知的 WebSocket 那一行，加上 127.0.0.1。版本对不上就失败，不会继续构建。

2

私密 token 文件

setup.mjs 写入权限 0600 的设置，并且不打印 bearer token。只启动一个网关，由它持有 stdio 后端。

3

私有 HTTPS

tailscale serve 只反代到 127.0.0.1。不要开 Funnel。在 Grok Bot 里先认证 Tailscale，再添加远程 HTTP 连接器。

4

打开面板

用 Figma Desktop，不要用浏览器。导入 figma-plugin/manifest.json。让 figma-unified-mcp 保持绿色 Connected。

5

只测空白文件

先看状态，做一次读取。只有你明确同意时才创建一个临时节点，然后删除。不要从正式设计文件开始。

运行规则18211 端口只能有一个后端。端口被占用时，网关会打印那个 PID 并退出。它不会做宽泛的 kill。面板和文件开着时，可以切换到其他应用。
停止条件不要用 Bot 本机命令连接器，不要开 Tailscale Funnel，不要用 Figma 网页版，也不要在聊天里发送 Figma REST token。权限错误或面板断开时停止操作。
