Workflow diagram · not a screenshot
1

Pin and patch

fetch-upstream.mjs checks out one commit, requires the known WebSocket line, sets host 127.0.0.1, and fails closed on mismatch.

2

Private token file

setup.mjs writes mode 0600 settings and does not print the bearer token. Start one gateway. It owns the stdio backend.

3

Private HTTPS

tailscale serve to 127.0.0.1 only. Funnel stays off. In Grok Bot, authenticate Tailscale, then add the remote HTTP connector.

4

Open the panel

Figma Desktop, not the browser. Import figma-plugin/manifest.json. Leave figma-unified-mcp green Connected.

5

Blank file only

Check status, read once, then one temporary node if you explicitly agree. Delete it. Do not start on a real design file.

Operational rulesOnly one backend may hold port 18211. If it is busy, the gateway prints that PID and stops. It does not run a broad kill. You can switch apps while the panel and file stay open.
Stop conditionsDo not use the bot-local command connector, Tailscale Funnel, Figma Web, or a Figma REST token in chat. Permission errors and a disconnected panel stop the work.
